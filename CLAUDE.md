# Repository Notes

This repository is a public portfolio copy of the BogoBogo dashboard and Virtual Map work.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

No test runner is configured in this public copy.

## Scope

The root `src/` folder contains the existing public dashboard prototype. The `portfolio/` and `docs/` folders contain curated source samples and explanations from the larger capstone monorepo.

Do not add private `.env` files, API keys, database credentials, Unity builds, raw media, or third-party licensed asset folders to this repository.
